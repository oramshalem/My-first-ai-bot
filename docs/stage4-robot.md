# שלב 4: שיחה ראשונה על הרובוט

הדרך: צורבים ללוח את הקושחה המוכנה של [xiaozhi-esp32](https://github.com/78/xiaozhi-esp32), שתומכת בלוח שלנו, ומכוונים אותה לגשר שרץ על המחשב. הגשר מדבר עם הרובוט בשפה של xiaozhi ועם Gemini בשפה של Google. הוא משתמש באותו שרת טוקנים ובאותו מסך לוגים, כך שה-prompt, המפתח וההיסטוריה לא זזים.

```
רובוט (xiaozhi)  ⇄  גשר, פורט 8788  ⇄  Gemini Live
                        ⇅
              שרת טוקנים ולוגים, פורט 8787
```

לא צריך להתקין ESP-IDF ולא לקמפל כלום.

## לפני שמתחילים

- **גרסת הלוח:** הקושחה המוכנה בנויה ל-V2, הגרסה שנמכרת מאז ינואר 2026. אם על הלוח כתוב V1, השמע לא יעבוד עם הקושחה הזאת. במקרה כזה צריך קושחה שנבנית במיוחד. תגיד לי ואבנה.
- **המחשב והרובוט באותה רשת Wi-Fi.**
- **השרת רץ על המחשב:** `npm run local` בתיקייה `worker`, כמו בבדיקות מהדפדפן. הפקודה מפעילה עכשיו גם את הגשר, ומדפיסה שורה כזאת:

  ```
  Robot setup page, field OTA (advanced):
    http://192.168.1.68:8788/xiaozhi/ota/
  ```

  את הכתובת הזאת נכניס לרובוט בהמשך. אם Windows שואל אם לאפשר ל-Node גישה לרשת, מאשרים לרשתות פרטיות.

## 1. הורדת הקושחה

1. נכנסים לדף [הגרסאות של xiaozhi](https://github.com/78/xiaozhi-esp32/releases/latest).
2. תחת Assets מורידים את `v2.5.2_waveshare-esp32-s3-touch-lcd-1.85c.zip`. אם יש גרסה חדשה יותר, את הקובץ עם אותו סיום.
3. פותחים את ה-zip. בפנים יש `merged-binary.bin`.

## 2. צריבה מהדפדפן

1. מחברים את הלוח למחשב בכבל USB-C שמעביר נתונים.
2. פותחים ב-Chrome את [ESP Tool](https://espressif.github.io/esptool-js/).
3. לוחצים Connect ובוחרים את הלוח מהרשימה. אם הוא לא מופיע: מחזיקים את כפתור BOOT, מחברים את הכבל, משחררים ומנסים שוב.
4. בשדה Flash Address משאירים `0x0`, ובוחרים את `merged-binary.bin`.
5. לוחצים Program ומחכים שיגיע ל-100%. זה לוקח כדקה.
6. מנתקים ומחברים את הכבל, או לוחצים על כפתור RESET.

## 3. הגדרת Wi-Fi וכתובת הגשר

הסדר חשוב: את כתובת הגשר מכניסים **לפני** ששומרים את ה-Wi-Fi. אחרת, בחיבור הראשון הרובוט יפנה לשרת של xiaozhi בסין.

1. אחרי ההדלקה הרובוט פותח רשת Wi-Fi משלו, בשם שמתחיל ב-`Xiaozhi`. המסך מציג את השם.
2. מתחברים אליה מהטלפון. אם דף ההגדרות לא נפתח לבד, פותחים בדפדפן `http://192.168.4.1`.
3. נכנסים ללשונית Advanced, ובשדה OTA מדביקים את הכתובת ש-`npm run local` הדפיס, למשל `http://192.168.1.68:8788/xiaozhi/ota/`. שומרים.
4. חוזרים ללשונית הראשית, בוחרים את רשת ה-Wi-Fi של הבית, מזינים סיסמה ומתחברים.
5. הרובוט מתחבר לרשת וניגש לגשר. בחלון של `npm run local` תופיע השורה `[robot] paired with robot ...`. מעכשיו הגשר יעבוד רק עם הלוח הזה.

## 4. שיחה

1. לוחצים פעם אחת על כפתור BOOT. פיקו מתחבר ואומר שלום.
2. מדברים. הרובוט ממשיך להקשיב אחרי כל תשובה, עד שלוחצים שוב על BOOT.
3. כל שיחה מופיעה במסך הלוגים, `http://localhost:8787/logs`, עם תמלול וזמן תגובה.

כמה דברים שכדאי לדעת על הקושחה המוכנה:
- **בזמן שפיקו מדבר הוא לא מקשיב.** לכן אי אפשר לקטוע אותו באמצע, אבל גם אין בעיה של הד מהרמקול.
- **המסך מציג מצבים ופרצופים, והטקסט באנגלית.** תמלול בעברית לא יוצג על המסך.
- **צריך ללחוץ על BOOT בכל הדלקה.** האזנה מהרגע שמדליקים דורשת שינוי קטן בקושחה. זה הצעד הבא.

## כשמשהו לא עובד

| מה רואים | מה עושים |
|----------|-----------|
| המסך אומר שאין חיבור לשרת | בודקים ש-`npm run local` רץ, ושהכתובת בשדה OTA היא של המחשב ולא `localhost` |
| `[robot] robot ... is not paired` | הגשר כבר צומד ללוח אחר. מוחקים את `worker/.robot.json` ומפעילים את הרובוט מחדש |
| `could not start Gemini` | אותה בעיה כמו בדפדפן. הסיבה המדויקת מופיעה במסך הלוגים |
| `Gemini closed the connection` | Gemini מגביל אורך שיחה. לוחצים שוב על BOOT ומתחילים שיחה חדשה |
| הרובוט מדבר בקטעים | Wi-Fi חלש. מקרבים את הרובוט לראוטר |
