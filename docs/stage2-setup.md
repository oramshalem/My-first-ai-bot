# שלב 2: הכנת סביבה עד שהלוח מגיע

החומרה הוזמנה: Waveshare ESP32-S3-Touch-LCD-1.85C-BOX עם סוללה. את כל מה שכאן אפשר לעשות לפני שהמשלוח מגיע, חוץ מחלק ד.

## א. חשבונות

### OpenAI Platform

1. נכנסים ל-platform.openai.com ומוסיפים אמצעי תשלום.
2. יוצרים פרויקט חדש בשם `kids-robot`. ככה העלות של הרובוט נפרדת מכל שימוש אחר.
3. בהגדרות ה-Limits של הארגון מגדירים מגבלת הוצאה חודשית של 10 עד 15 דולר, והתראה במייל ב-50%.
4. יוצרים מפתח API בתוך הפרויקט ושומרים אותו במנהל סיסמאות. המפתח לא נכנס לריפו, לא לקובץ במחשב ולא לקושחה. בשלב 3 הוא יעבור ישירות ל-Cloudflare כ-secret.

### Google AI Studio

1. נכנסים ל-aistudio.google.com עם חשבון Google.
2. יוצרים מפתח Gemini API לבדיקה של החלופה.
3. לא מחברים חיוב בשלב הזה.

### Cloudflare

1. פותחים חשבון חינמי ב-dash.cloudflare.com.
2. לא צריך להגדיר שום דבר נוסף עכשיו. ה-Worker, ה-KV וה-D1 נוצרים בשלב 3.

## ב. סביבת פיתוח בווינדוס

1. **ESP-IDF 5.x**: מתקינים מ-ESP-IDF Windows Installer של Espressif, או דרך תוסף ESP-IDF ב-VS Code. בוחרים בגרסה היציבה האחרונה מסדרה 5. ההתקנה מוסיפה לתפריט התחל קיצור בשם "ESP-IDF PowerShell", ומשם מריצים את כל פקודות `idf.py`.
2. **Node.js LTS**: מ-nodejs.org. אחרי ההתקנה בודקים ש-`node -v` עובד. את Wrangler נתקין בשלב 3 בתוך הפרויקט.
3. **Python 3.11**: אם ESP-IDF התקין Python משלו, זה מספיק לעכשיו.
4. **Git**: אם עוד לא מותקן, מ-git-scm.com. אחר כך משכפלים את הריפו הזה למחשב.

בדיקה שההתקנה עובדת, עוד בלי לוח. ב-ESP-IDF PowerShell:

```powershell
cd $env:IDF_PATH\examples\get-started\hello_world
idf.py set-target esp32s3
idf.py build
```

אם ה-build נגמר בלי שגיאות, הסביבה מוכנה.

## ג. רכישות קטנות

- כבל USB-C שמעביר נתונים. אם הלוח לא מופיע במחשב, הסיבה הנפוצה היא כבל שמיועד לטעינה בלבד.

## ד. כשהלוח מגיע

1. **בודקים איזו גרסה הגיעה.** מחפשים על הלוח או על האריזה סימון V1 או V2, ומצלמים אותו. זה קובע איזו הגדרת לוח נשתמש בה בשלב 4.
2. **בודקים את הסוללה.** מחברים לטעינה ב-USB-C ובודקים שהלוח והסוללה לא מתחממים בצורה חריגה. את הטעינות הראשונות עושים רק בהשגחה.
3. **מסתכלים על הקושחה שהגיעה מהמפעל.** מדליקים ורואים מה מופיע על המסך. לא מחברים אותה ל-Wi-Fi ולא נותנים לילדים לדבר איתה: קושחות xiaozhi מהמפעל מתחברות לשרתים בסין כברירת מחדל.
4. **צריבה ראשונה של hello_world.** מחברים למחשב, ובודקים ב-Device Manager תחת Ports איזה COM קיבל הלוח, למשל COM5. ואז:

   ```powershell
   cd $env:IDF_PATH\examples\get-started\hello_world
   idf.py -p COM5 flash monitor
   ```

   אם הלוח לא מופיע או שהצריבה לא מתחילה, מחזיקים את כפתור BOOT, מחברים את הכבל ואז משחררים, ומנסים שוב. יוצאים מה-monitor עם `Ctrl+]`.

הצריבה הזאת מוחקת את קושחת המפעל. זה בסדר: בשלב 4 נצרוב קושחה משלנו שמדברת עם השרת שלנו.
