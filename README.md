# רובוט AI מדבר לילדים

רובוט שולחני קטן שמנהל שיחה קולית בעברית עם ילדים בגילאי 4 עד 10. הלוח הוא ESP32-S3 (Waveshare ESP32-S3-Touch-LCD-1.85C-BOX), והמוח הוא מודל speech-to-speech בענן שמתחבר דרך שרת טוקנים משלנו.

האפיון המלא ותוכנית העבודה: [docs/plan.md](docs/plan.md)

## איפה אנחנו

| שלב | מה | מצב |
|-----|-----|-----|
| 1 | בדיקת ספקים ודמות | בעבודה |
| 2 | הזמנת חומרה והכנת סביבה | |
| 3 | שרת טוקנים (Cloudflare Worker) | |
| 4 | שיחה ראשונה על הרובוט | |
| 5 | אופי וגוף | |
| 6 | שכבת הורים | |

אין מעבר לשלב הבא בלי שכל תנאי השער מסומנים ויש אישור.

## מבנה הריפו

```
docs/plan.md                  אפיון ותוכנית עבודה
docs/stage1-provider-test.md  פרוטוקול וטבלת השוואה לשלב 1
prompts/character_v1.md       system prompt של הדמות
```

בשלבים הבאים יתווספו `worker/` לשרת הטוקנים ו-`firmware/` לקושחה.

## כללים

- מפתחות API לא נכנסים לריפו ולא לקושחה. המפתח יושב כ-secret ב-Worker בלבד.
- `sdkconfig` וקבצי `.env` / `.dev.vars` ב-`.gitignore`.
