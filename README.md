# רובוט AI מדבר לילדים

רובוט שולחני קטן שמנהל שיחה קולית בעברית עם ילדים בגילאי 4 עד 10. הלוח הוא ESP32-S3 (Waveshare ESP32-S3-Touch-LCD-1.85C-BOX), והמוח הוא מודל speech-to-speech בענן שמתחבר דרך שרת טוקנים משלנו.

האפיון המלא ותוכנית העבודה: [docs/plan.md](docs/plan.md)

## איפה אנחנו

| שלב | מה | מצב |
|-----|-----|-----|
| 1 | בדיקת ספקים ודמות | בעבודה |
| 2 | הזמנת חומרה והכנת סביבה | חומרה הוזמנה, ממתינים למשלוח |
| 3 | שרת טוקנים | עובד עם Gemini מהדפדפן, כולל תמלול בעברית. זמן תגובה 1.57 שניות בממוצע. ממתין לאישור השער |
| 4 | שיחה ראשונה על הרובוט | הגשר מוכן ונבדק מול רובוט מדומה. ממתין ללוח |
| 5 | אופי וגוף | |
| 6 | שכבת הורים | |

אין מעבר לשלב הבא בלי שכל תנאי השער מסומנים ויש אישור.

## מבנה הריפו

```
docs/plan.md                  אפיון ותוכנית עבודה
docs/stage1-provider-test.md  פרוטוקול וטבלת השוואה לשלב 1
docs/stage2-setup.md          חשבונות, סביבת פיתוח וצריבה ראשונה
docs/stage4-robot.md          צריבת הרובוט וחיבור לגשר
prompts/character_v1.txt      system prompt של הדמות (מקור יחיד)
prompts/character_v1.md       הערות ויומן שינויים ל-prompt
worker/                       שרת הטוקנים, דף בדיקה, מסך לוגים וגשר לרובוט
```

הרובוט משתמש בקושחה המוכנה של xiaozhi-esp32, ולכן אין כאן תיקיית קושחה. שינויים בקושחה, אם יידרשו, ייכנסו ל-`firmware/`.

## כללים

- מפתחות API לא נכנסים לריפו ולא לקושחה. המפתח יושב רק בשרת: ב-`.dev.vars` במחשב, או כ-secret ב-Cloudflare.
- `sdkconfig` וקבצי `.env` / `.dev.vars` ב-`.gitignore`.
