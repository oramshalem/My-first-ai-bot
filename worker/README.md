# שרת טוקנים (שלב 3)

שרת קטן שמחזיק את מפתח ה-API ונותן לרובוט טוקן זמני לשיחה. הרובוט והדפדפן אף פעם לא רואים את המפתח עצמו. הוא תומך בשני ספקים, Gemini Live ו-OpenAI Realtime. ברירת המחדל היא Gemini.

## מה יש כאן

- `POST /token`: מקבל מזהה מכשיר וסוד, ומחזיר טוקן זמני מהספק. ה-prompt, המודל והקול נקבעים כאן בשרת ונעולים בתוך הטוקן.
- `GET /`: דף בדיקה. הוא מתחבר לשיחה מהדפדפן, מציג תמלול ומודד זמן תגובה.
- `GET /logs`: מסך לוגים מוגן בסיסמה. כל שיחה נרשמת שם אוטומטית.
- `POST /log`: לכאן הדפדפן והגשר שולחים מה קרה בשיחה.
- `bridge/xiaozhi-bridge.mjs`: הגשר לרובוט, בפורט 8788. הוא מדבר עם קושחת xiaozhi ועם Gemini, ומקבל טוקן מ-`/token` בתור `robot-1`. ההוראות לרובוט נמצאות ב-[../docs/stage4-robot.md](../docs/stage4-robot.md).
- ה-prompt נטען מ-[../prompts/character_v1.txt](../prompts/character_v1.txt). אחרי שינוי צריך להפעיל את השרת מחדש.

## לפני שמתחילים: מפתח Gemini

1. נכנסים ל-[aistudio.google.com](https://aistudio.google.com) עם חשבון Google.
2. לוחצים Get API key ויוצרים מפתח. מפתחות חדשים מתחילים ב-`AQ.`, וישנים ב-`AIza`. שניהם עובדים.
3. לא מחברים חיוב. במסלול החינמי יש מכסה יומית, ואם עוברים אותה, השיחה פשוט נכשלת עד למחרת ולא מחייבים אותך.

שימו לב: במסלול החינמי Google רשאית להשתמש בשיחות לשיפור המוצרים שלה, וייתכן שאנשים אצלם יקראו אותן. תנאי השימוש של Gemini API גם אוסרים שימוש באפליקציות לילדים מתחת לגיל 18. לכן ההגדרה הזאת מתאימה לבדיקה של מבוגר בלבד.

## הרצה על המחשב בבית

צריך Node.js ו-Git מותקנים. כל הפקודות רצות ב-PowerShell.

1. מורידים את הקוד, פעם אחת:

   ```powershell
   git clone -b claude/new-session-c94dqs https://github.com/oramshalem/My-first-ai-bot.git
   cd My-first-ai-bot\worker
   npm install
   ```

   אם כבר הורדת בעבר, מעדכנים במקום זה עם `git pull` ואז `npm install`.

2. מכינים את ההגדרות, פעם אחת:

   ```powershell
   npm run setup-local
   ```

   הסקריפט מבקש את מפתח Gemini. את מפתח OpenAI אפשר לדלג עליו עם Enter. הוא מייצר לבד את הסודות ואת סיסמת הלוגים ומדפיס אותם. שומרים אותם במנהל סיסמאות. הכל נשמר בקובץ `.dev.vars`, שנמצא ב-`.gitignore` ולא עולה ל-GitHub.

3. מפעילים את השרת. מריצים את זה בכל פעם שרוצים לדבר עם פיקו:

   ```powershell
   npm run local
   ```

   לפני שהשרת עולה, הפקודה בודקת את `.dev.vars` ומדפיסה ✓ לכל הגדרה תקינה. אם משהו חסר, היא עוצרת ואומרת מה לתקן. בטבלה שמופיעה אחר כך צריכה להופיע השורה `env.DEVICE_KEYS ("(hidden)")`.

   החלון צריך להישאר פתוח, ו-`Ctrl+C` עוצר את השרת. בפעם הראשונה Windows עשוי לשאול אם לאפשר ל-Node גישה לרשת. מאשרים לרשתות פרטיות בלבד.

4. `npm run local` מדפיס קישור לדף הבדיקה, `Test page`. פותחים אותו ב-Ctrl+לחיצה, והוא ממלא לבד את המזהה ואת הסוד. אחרי שיחה מוצלחת הדף זוכר אותם, ואז מספיק `http://localhost:8787`.
   מסך הלוגים נמצא ב-`http://localhost:8787/logs`, עם הסיסמה מסעיף 2.

5. לוחצים "התחל שיחה" ומאשרים גישה למיקרופון. פיקו אמור להגיד שלום, ומשם פשוט מדברים: ברירת המחדל היא "מקשיב כל הזמן". Gemini מחכה לשקט של 0.7 שניות לפני שהוא עונה, כדי לא לקטוע באמצע משפט. את המשך הזה קובעים ב-`GEMINI_SILENCE_MS` ב-[wrangler.toml](wrangler.toml): ערך ארוך יותר אומר פחות קטיעות ותשובה איטית יותר. יש גם מצב "לחץ ודבר": מחזיקים את הכפתור, או את מקש הרווח, כל זמן שמדברים. עם Gemini כדאי לדבר עם אוזניות, אחרת פיקו עלול לשמוע את עצמו מהרמקולים ולקטוע את עצמו.

את הבדיקה עושים מהמחשב עצמו ולא מהטלפון. Chrome מאפשר גישה למיקרופון רק ב-`localhost` או ב-https.

בשלב 4 הרובוט יתחבר לשרת דרך כתובת המחשב ברשת הביתית, למשל `http://192.168.1.20:8787`. את הכתובת מוצאים עם `ipconfig`, בשורה IPv4 Address.

## מסך הלוגים

הכל נרשם בלי לעשות כלום:

- סיכום: מספר שיחות, דקות שיחה, זמן תגובה ממוצע ושגיאות. זמן תגובה עד 1.5 שניות מופיע בירוק, מעליו באדום.
- כל שיחה: לחיצה פותחת את התמלול המלא לפי שעה, עם זמן התגובה אחרי כל פנייה ועם שגיאות.
- בקשות שנדחו: כל ניסיון לקבל טוקן עם סוד שגוי, וכל תקלה מול הספק, עם הודעת השגיאה המלאה.
- הכפתור "העתק כטקסט" מעתיק שיחה שלמה, כדי להדביק לי בצ'אט אם צריך לנתח משהו.

המסך מתעדכן לבד כל 15 שניות. נשמר רק טקסט, בלי אודיו.

## כשמשהו לא עובד

- **401, ובחלון של השרת מופיע `DEVICE_KEYS is not set` או `not valid JSON`**: קובץ ההגדרות חסר או פגום. מריצים `npm run check-local`, שמסביר מה לא תקין בלי להדפיס סודות. הפתרון הרגיל הוא למחוק את `.dev.vars`, להריץ `npm run setup-local` ולהפעיל את `npm run local` מחדש.
- **"השרת החזיר 502"**: הספק דחה את בקשת הטוקן. הסיבה המדויקת מופיעה במסך הלוגים, תחת "בקשות שנדחו ותקלות שרת".
- **404 מ-Gemini**: התיעוד של Google לא אחיד לגבי גרסת ה-API. משנים ב-[wrangler.toml](wrangler.toml) את `GEMINI_API_VERSION` ל-`"v1beta"` ומפעילים מחדש.
- **מודל לא נמצא**: בודקים ב-AI Studio את שם מודל ה-Live הנוכחי ומעדכנים את `GEMINI_MODEL`.
- **התמלול של מה שאמרת יוצא בספרדית או בגרמנית**: זה רק התמלול ללוג, והמודל עצמו מבין עברית. `GEMINI_TRANSCRIBE_LANGUAGE = "he-IL"` אמור לתקן את זה. אם בגללו Gemini סוגר את החיבור עם 1007, משנים ל-`""`.
- **"Gemini סגר את החיבור"**: הקוד וההסבר מופיעים בסטטוס ובמסך הלוגים. אחת הסיבות האפשריות היא חריגה מהמכסה החינמית.
- "לוג אירועים" בתחתית דף הבדיקה מראה כל הודעה שהגיעה מהספק.

## שינוי הגדרות

כל ההגדרות שאינן סודיות נמצאות תחת `[vars]` ב-[wrangler.toml](wrangler.toml):

- `PROVIDER`: `"gemini"` או `"openai"`.
- `GEMINI_MODEL`, `GEMINI_VOICE`: המודל והקול של Gemini. ברירת המחדל לקול היא `Puck`. קולות אחרים לנסות: `Kore`, `Aoede`, `Leda`, `Zephyr`.
- `OPENAI_MODEL`, `OPENAI_VOICE`: אותו דבר ל-OpenAI.

אחרי שינוי עוצרים את `npm run local` ומפעילים מחדש. ככה מחליפים קול או ספק בלי לגעת בקושחה.

## פריסה ל-Cloudflare

כשהרובוט צריך לעבוד גם כשהמחשב כבוי. כל הפקודות רצות מתוך התיקייה `worker`.

1. מתחברים ל-Cloudflare. ייפתח דפדפן לאישור:

   ```powershell
   npx wrangler login
   ```

2. פורסים:

   ```powershell
   npx wrangler deploy
   ```

   בסוף מופיעה כתובת בצורה `https://kids-robot-token.<השם-שלך>.workers.dev`. בפריסה הראשונה wrangler יוצר לבד את בסיס הנתונים `kids-robot-logs`. אם הוא שואל אם ליצור, עונים כן.

3. מעבירים את הסודות. כל פקודה מבקשת להדביק ערך, והערכים הם אותם ערכים שנמצאים ב-`.dev.vars`:

   ```powershell
   npx wrangler secret put GEMINI_API_KEY
   npx wrangler secret put DEVICE_KEYS
   npx wrangler secret put ADMIN_PASSWORD
   ```

   אם משתמשים גם ב-OpenAI, מוסיפים `npx wrangler secret put OPENAI_API_KEY`.

4. פותחים את הכתובת ב-Chrome, במחשב או בטלפון. ב-Cloudflare יש https, אז גם הטלפון יקבל מיקרופון.

## הממשק לרובוט

```
POST /token
X-Device-Id: robot-1
Authorization: Bearer <סוד המכשיר>
```

תשובה מוצלחת עם Gemini:

```json
{ "provider": "gemini", "model": "gemini-3.8-live", "session_id": "...",
  "token": "auth_tokens/...", "ws_url": "wss://generativelanguage.googleapis.com/ws/...", "expires_at": 1767000000 }
```

הרובוט פותח WebSocket ל-`ws_url?access_token=<token>`, שולח `{"setup":{"model":"models/<model>"}}`, מחכה ל-`setupComplete`, ואז שולח אודיו PCM של 16 ביט, מונו, 16kHz, בהודעות `realtimeInput`. אודיו התשובה מגיע ב-24kHz. ההגדרות האמיתיות, כלומר ה-prompt, הקול והתמלול, נעולות בטוקן, וכל הגדרה אחרת שהרובוט שולח נדחית.

תשובה מוצלחת עם OpenAI:

```json
{ "provider": "openai", "model": "gpt-realtime-2.1-mini", "session_id": "...", "client_secret": "ek_...", "expires_at": 1767000000 }
```

עם ה-`client_secret` שולחים SDP offer ל-`https://api.openai.com/v1/realtime/calls`.

ברירת המחדל היא האזנה רציפה: הספק מזהה לבד את סוף הדיבור. עם `?mode=push` הזיהוי האוטומטי כבוי. ב-Gemini המכשיר שולח `{"realtimeInput":{"activityStart":{}}}` כשהכפתור נלחץ ו-`{"realtimeInput":{"activityEnd":{}}}` כשהוא משוחרר. ב-OpenAI הוא שולח `input_audio_buffer.commit` ואז `response.create`. 

מכשיר לא מוכר או סוד שגוי מקבלים 401. אם הספק דוחה או לא זמין, התשובה היא 502.

במהלך השיחה הרובוט מדווח ללוג עם אותן כותרות:

```
POST /log
{ "session_id": "...", "events": [ { "at": 1767000000000, "kind": "kid", "text": "..." } ] }
```

סוגי אירועים: `kid`, `robot`, `latency` (עם `ms`), `status`, `error`, `end`. אפשר לשלוח עד 50 אירועים בבקשה.
