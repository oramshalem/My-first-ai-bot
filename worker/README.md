# שרת טוקנים (שלב 3)

Cloudflare Worker שמחזיק את מפתח OpenAI ונותן לרובוט טוקן זמני לשיחה. הרובוט והדפדפן אף פעם לא רואים את המפתח עצמו.

## מה יש כאן

- `POST /token`: מקבל מזהה מכשיר וסוד, ומחזיר client secret זמני מ-OpenAI. ה-prompt, המודל והקול נקבעים כאן בשרת.
- `GET /`: דף בדיקה. הוא מתחבר לשיחה מהדפדפן, מציג תמלול ומודד זמן תגובה.
- `GET /logs`: מסך לוגים מוגן בסיסמה. כל שיחה נרשמת שם אוטומטית.
- `POST /log`: לכאן הדפדפן, ואחר כך הרובוט, שולחים מה קרה בשיחה.
- ה-prompt נטען מ-[../prompts/character_v1.txt](../prompts/character_v1.txt). אחרי שינוי שם צריך לעשות deploy מחדש.

## שתי דרכים להריץ

| | על המחשב בבית | ב-Cloudflare |
|-|---------------|--------------|
| חשבון Cloudflare | לא צריך | צריך (חינמי) |
| המחשב חייב להיות דלוק | כן | לא |
| עובד מחוץ לבית | לא | כן |
| הלוגים נשמרים | בתיקייה `worker/.wrangler` במחשב | ב-D1 בענן |

לשלב 3, ובהתחלה של שלב 4, המחשב בבית מספיק. כשהרובוט צריך לעבוד גם כשהמחשב כבוי, עוברים ל-Cloudflare עם פקודה אחת. הקוד זהה בשתי הדרכים.

## הרצה על המחשב בבית

צריך Node.js ו-Git מותקנים. כל הפקודות רצות ב-PowerShell.

1. מורידים את הקוד, פעם אחת:

   ```powershell
   git clone -b claude/new-session-c94dqs https://github.com/oramshalem/My-first-ai-bot.git
   cd My-first-ai-bot\worker
   npm install
   ```

2. מכינים את ההגדרות, פעם אחת. הסקריפט מבקש רק את מפתח OpenAI, ומייצר לבד את הסודות ואת סיסמת הלוגים:

   ```powershell
   npm run setup-local
   ```

   הוא מדפיס את סוד דף הבדיקה, את סוד הרובוט ואת סיסמת הלוגים. שומרים אותם במנהל סיסמאות. הכל נשמר בקובץ `.dev.vars`, שנמצא ב-`.gitignore` ולא עולה ל-GitHub.

3. מפעילים את השרת. מריצים את זה בכל פעם שרוצים לדבר עם פיקו:

   ```powershell
   npm run local
   ```

   החלון צריך להישאר פתוח, ו-`Ctrl+C` עוצר את השרת. בפעם הראשונה Windows עשוי לשאול אם לאפשר ל-Node גישה לרשת. מאשרים לרשתות פרטיות בלבד.

4. פותחים ב-Chrome על אותו מחשב:
   - `http://localhost:8787`: דף הבדיקה. מזהה מכשיר `browser-test`, והסוד מסעיף 2.
   - `http://localhost:8787/logs`: מסך הלוגים, עם הסיסמה מסעיף 2.

את הבדיקה עושים מהמחשב עצמו ולא מהטלפון. Chrome מאפשר גישה למיקרופון רק ב-`localhost` או ב-https, ולכן כתובת כמו `http://192.168.1.20:8787` מהטלפון לא תקבל מיקרופון.

בשלב 4 הרובוט יתחבר לשרת דרך כתובת המחשב ברשת הביתית, למשל `http://192.168.1.20:8787`. את הכתובת מוצאים עם `ipconfig`, בשורה IPv4 Address. בשביל זה `npm run local` מאזין לכל הרשת הביתית ולא רק למחשב עצמו.

## פריסה ל-Cloudflare

כל הפקודות רצות מתוך התיקייה `worker` ב-PowerShell.

1. מתקינים:

   ```powershell
   npm install
   ```

2. מתחברים ל-Cloudflare. ייפתח דפדפן לאישור:

   ```powershell
   npx wrangler login
   ```

3. פורסים:

   ```powershell
   npx wrangler deploy
   ```

   בסוף מופיעה כתובת בצורה `https://kids-robot-token.<השם-שלך>.workers.dev`. שומרים אותה.

   בפריסה הראשונה wrangler יוצר לבד את בסיס הנתונים `kids-robot-logs`. אם הוא שואל אם ליצור, עונים כן. את הטבלאות השרת יוצר בעצמו בבקשה הראשונה.

4. מייצרים שני סודות אקראיים, אחד לדפדפן ואחד לרובוט. מריצים את הפקודה פעמיים:

   ```powershell
   node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
   ```

5. מגדירים את מפתח OpenAI. הפקודה מבקשת להדביק את הערך:

   ```powershell
   npx wrangler secret put OPENAI_API_KEY
   ```

6. מגדירים את רשימת המכשירים. מדביקים שורה אחת בפורמט JSON, עם שני הסודות מסעיף 4:

   ```powershell
   npx wrangler secret put DEVICE_KEYS
   ```

   ```json
   {"browser-test":"<סוד ראשון>","robot-1":"<סוד שני>"}
   ```

   את שני הסודות שומרים במנהל סיסמאות. הסוד של `robot-1` ייכנס להגדרות הלוח בשלב 4.

7. מגדירים סיסמה למסך הלוגים. כדאי לבחור סיסמה ארוכה, כי במסך יש את כל מה שהילדים אמרו:

   ```powershell
   npx wrangler secret put ADMIN_PASSWORD
   ```

## בדיקה מהדפדפן

1. פותחים את כתובת ה-Worker ב-Chrome, במחשב או בטלפון.
2. מזהה מכשיר: `browser-test`. סוד: הסוד הראשון.
3. לוחצים "התחל שיחה" ומאשרים גישה למיקרופון. פיקו אמור להגיד שלום.
4. מדברים. התמלול וזמן התגובה מופיעים בדף.

## מסך הלוגים

פותחים את `<כתובת ה-Worker>/logs` ומזינים את סיסמת ההורה. הכל נרשם בלי לעשות כלום:

- סיכום: מספר שיחות, דקות שיחה, זמן תגובה ממוצע ושגיאות. זמן תגובה עד 1.5 שניות מופיע בירוק, מעליו באדום.
- כל שיחה: לחיצה פותחת את התמלול המלא לפי שעה, עם זמן התגובה אחרי כל פנייה של הילד ועם שגיאות.
- בקשות שנדחו: כל ניסיון לקבל טוקן עם סוד שגוי, וכל תקלה מול OpenAI.
- הכפתור "העתק כטקסט" מעתיק שיחה שלמה. אפשר להדביק אותה לי בצ'אט אם צריך לנתח משהו.

המסך מתעדכן לבד כל 15 שניות. נשמר רק טקסט, בלי אודיו.


המודל, הקול, מודל התמלול ותוקף הטוקן נמצאים תחת `[vars]` ב-[wrangler.toml](wrangler.toml). משנים שם ועושים `npx wrangler deploy`. ככה עוברים בין קולות בלי לגעת בקושחה.

השרת המקומי משתמש בבסיס נתונים מקומי משלו, כך שלוגים מהמחשב לא מתערבבים עם הלוגים ב-Cloudflare. מחיקה של התיקייה `.wrangler` מוחקת את הלוגים המקומיים.

## הממשק לרובוט

```
POST /token
X-Device-Id: robot-1
Authorization: Bearer <סוד המכשיר>
```

תשובה מוצלחת:

```json
{ "client_secret": "ek_...", "expires_at": 1767000000, "model": "gpt-realtime-2.1-mini", "session_id": "..." }
```

עם ה-`client_secret` הרובוט שולח SDP offer ל-`https://api.openai.com/v1/realtime/calls`, בדיוק כמו דף הבדיקה. מכשיר לא מוכר או סוד שגוי מקבלים 401. אם OpenAI לא זמין, התשובה היא 502.

במהלך השיחה הרובוט מדווח ללוג עם אותן כותרות:

```
POST /log
{ "session_id": "...", "events": [ { "at": 1767000000000, "kind": "kid", "text": "..." } ] }
```

סוגי אירועים: `kid`, `robot`, `latency` (עם `ms`), `status`, `error`, `end`. אפשר לשלוח עד 50 אירועים בבקשה.
